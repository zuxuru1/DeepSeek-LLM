# Security Policy

## Reporting Security Issues

The DeepSeek team takes the security of our models and software repositories seriously.

If you discover a security vulnerability or sensitive security issue in this repository or associated DeepSeek LLM artifacts, please **DO NOT** create a public issue or discussion.

Instead, please report security vulnerabilities responsibly by emailing us at:
**[service@deepseek.com](mailto:service@deepseek.com)**

Please include:
- A description of the issue or vulnerability
- Steps or proof-of-concept to reproduce the issue
- Potential impact of the issue

We will acknowledge receipt of your report and work to address any verified security concerns promptly.

# Security Policy

## Reporting Security Issues

The DeepSeek team takes security vulnerabilities seriously. If you discover a security vulnerability or security-related issue in this repository, please do **NOT** open a public issue or pull request.

Instead, please report it privately:

- **Email**: `service@deepseek.com`

Please include as much detail as possible to help us reproduce and resolve the issue safely:
- Type of vulnerability / security concern
- Steps to reproduce
- Potential impact
- Suggested mitigations (if any)

We appreciate your assistance in keeping DeepSeek LLM safe and secure for everyone.
